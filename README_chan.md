# A 股缠论三买策略（可实操）

按缠论原文的结构层次逐层写成代码：**K 线包含处理 → 分型 → 笔 → 中枢 → 三类买卖点**，
不是用均线糊出来的"类三买"。所有信号只用截至当日收盘的数据，次日开盘执行。

## 一、代码结构

| 文件 | 作用 |
|---|---|
| `chan.py` | 缠论结构引擎：包含处理、分型、笔、中枢、三买/三卖 |
| `chan_strategy.py` | 三买策略：信号→组合→风控，含完整交易摩擦的回测器 |
| `run_chan.py` | 回测入口 |
| `chan_experiments.py` | 参数对照实验 |
| `chan_live.py` | 实盘信号：每日收盘后输出次日委托清单 CSV |
| `plot_chan.py` | 结构图：K 线 + 笔 + 中枢 + 买卖点 |
| `test_chan.py` | 结构算法的构造用例测试 |
| `data.py` / `backtest.py` | 行情数据层与交易成本模型（与动量版本共用） |

## 二、规则定义（本实现采用的这一套）

缠论有多个流派，实现前必须把规则钉死，本代码采用：

**包含处理**：相邻两根 K 线高低点互相包含时合并成一根，方向由前一段趋势决定
（向上取高高、低低中的高；向下反之）。

**分型**：处理后连续三根 K 线，中间高点最高 = 顶分型，中间低点最低 = 底分型。

**笔**：相邻的顶、底分型连线，要求两端分型间至少隔 `min_gap`（默认 3）根合并 K 线；
同向分型相邻时保留更极端的一个。

**中枢**：连续三笔的重叠区间，`ZG = min(三笔高点)`，`ZD = max(三笔低点)`，要求 `ZG > ZD`。
后续笔仍在区间内来回则中枢延伸；一旦出现「离开笔 + 不回中枢的回抽」，中枢结束。

**三买**（买入信号）：
1. 中枢结束后出现向上离开笔，笔高点 > `ZG × (1 + min_leave)`
2. 紧接着的向下回抽笔最低点仍 **> ZG**（没有回到中枢里）
3. 回抽笔的底分型被右侧 K 线确认（滞后 2 根合并 K 线）→ 当日收盘发信号
4. 收盘价必须仍在 ZG 之上，否则信号作废

**三卖**：与三买对称（向下离开中枢，反抽最高点仍 < ZD）。

## 三、交易与风控

- **买入**：T 日收盘确认三买，T+1 开盘买；同时满足上市满 250 交易日、20 日日均成交额 ≥ 5000 万、
  沪深 300 在 20 日均线上方
- **仓位**：等权 8 份，单票上限 15%；同日多个三买时优先买离 ZG 最近的（止损空间最小）
- **卖出**（任一触发，T+1 开盘卖）：
  1. 收盘跌回中枢上沿 ZG 之下 —— 三买失效，**这是最核心的止损位**
  2. 相对买入价亏损 10%
  3. 相对持仓最高价回撤 15%
  4. 出现三卖
  5. 沪深 300 跌破 20 日均线 → 清仓
- **摩擦**：佣金万 2.5（最低 5 元）、印花税千 1（卖出）、过户费万 0.1、滑点 0.1%、一手取整；
  停牌不可交易，开盘涨停买不到、跌停卖不掉

## 四、回测结果

样本：174 只大盘股（剔除价格数据异常的票），2016-01 ~ 2026-09，初始 100 万，全部费用已扣。

| 指标 | 缠论三买 | 沪深 300 |
|---|---|---|
| 总收益 | **192.8%** | 31.1% |
| 年化收益 | **11.0%** | 2.7% |
| 最大回撤 | **-24.4%** | -45.6% |
| 年化波动 | 15.4% | — |
| 夏普(rf=2%) | 0.62 | — |
| 月胜率 | 41.4% | — |
| 交易笔数 | 1392 | — |
| 个股胜率 | 46.7% | — |
| 单笔平均收益 | +1.6% | — |
| 总费用 | 22.1 万 | — |

卖出原因分布：大盘择时清仓 627 次、跌回中枢 31 次、止损 23 次、移动止损 15 次。
说明**大部分离场是被大盘择时触发的**，择时在这套策略里贡献很大。

### 参数对照（`chan_experiments.csv`）

| 变体 | 年化 | 最大回撤 | 夏普 |
|---|---|---|---|
| 基准 | 11.0% | -24.4% | 0.62 |
| 无大盘择时 | 13.8% | **-52.8%** | 0.58 |
| 无中枢破位离场 | 10.1% | -25.2% | 0.58 |
| 无移动止损 | 10.7% | -23.7% | 0.61 |
| 持仓 5 只 | 8.3% | -18.5% | 0.50 |
| 持仓 15 只 | 8.6% | -20.9% | 0.56 |
| 笔间隔 5 根（更严） | 13.2% | -15.2% | 0.86 |
| 离开中枢需 >3% | 11.2% | -24.4% | 0.64 |
| 择时用 60 日均线 | 8.9% | -29.0% | 0.45 |

结论：
- 各参数下年化都在 8%~13%，**结果不依赖某一组神奇参数**，这比单点高收益更重要
- 去掉大盘择时收益更高但回撤翻倍到 -53%，A 股系统性下跌时三买会连片失效
- "笔间隔 5 根"这组最好（年化 13.2%、回撤 -15.2%），但这是**样本内择优**，
  实盘请按默认的 3 跑，不要照抄最优参数

## 五、实操流程

```bash
# 1) 回测复现
python3 run_chan.py

# 2) 每个交易日 15:00 后跑一次，输出次日委托
python3 chan_live.py --positions positions.json

# 3) 看某只票的缠论结构
python3 plot_chan.py 600519 --start 2020-01-01 --end 2021-12-31
```

`positions.json`（买入后手工更新，`zg` 就是委托单里给出的中枢上沿）：

```json
{"cash": 100000,
 "positions": {"600519": {"shares": 100, "cost_price": 1500.0, "zg": 1480.0, "high_price": 1600.0}}}
```

输出 `chan_orders_YYYY-MM-DD.csv`，列含 code/name/side/shares/ref_price/reason。
次日 9:30 之后按清单下单：

- 开盘一字涨停买不进 → **直接放弃这个信号**，不要追高，三买的意义就在于止损位近
- 开盘跌停卖不掉 → 挂跌停价排队，次日继续卖
- 每次买入记下当时的 ZG，之后收盘跌破它就无条件走人

## 六、适用与失效场景

**有效**：个股走出震荡区间（中枢）后进入趋势段。三买的价值是**止损位明确且近**
（就是 ZG），单笔亏损可控。

**失效**：
- 系统性下跌市（2018、2022）中枢会连续下移，三买接连失败 —— 靠大盘择时规避
- 极端窄幅震荡的股票会反复产生假三买 —— 靠成交额和 `min_leave` 过滤
- 一字涨停突破的票根本买不进，回测里已按买不到处理

## 七、必须知道的局限

1. **股票池有幸存者偏差**：用当前市值排名倒推历史，退市股不在里面，真实收益会更低
2. 免费行情源（新浪/腾讯）会限流，复权因子口径与券商数据可能有差异；上表 174 只票是剔除
   复权异常后的可用样本，样本偏小
3. 缠论的"笔"和"中枢"有多种流派定义，换一套定义结果会变，本实现的规则见第二节
4. 回测按开盘价成交 + 0.1% 滑点，实盘小盘股冲击成本会更高
5. **年化 11% 是这套规则在这段历史上的结果，不是承诺**。月收益 15%（年化 435%）
   在 A 股不存在可持续实现路径
