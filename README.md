# A 股月度动量轮动策略（可实操）

## 先把话说清楚：月收益 15% 做不到

月收益 15% = 年化 435%，10 年 1 万变 5.9 亿。A 股（乃至全球）没有任何公开或私募策略能持续做到这个量级。
真实参照系：

| 参照 | 长期年化 |
| --- | --- |
| 沪深 300 | 约 5%~8% |
| 优秀公募主动权益 | 约 12%~18% |
| 头部私募量化指增 | 约 15%~25%（超额 10%~15%） |
| 顶级高频/T0（容量极小） | 30%+ |

任何承诺月化 15% 的产品或代码，只有三种情况：**样本内过拟合、隐藏了爆仓风险、或者是骗局**。

本仓库给的是一套**参数透明、含真实交易摩擦、可以直接照单下单**的策略，目标是长期跑赢沪深 300，
而不是虚构一个漂亮的回测曲线。

## 策略逻辑

一句话：**大盘在 20 日线上方时，持有 10 只中期动量最强、短期不过热、波动率不高的股票，每月换一次仓，跌破纪律就走。**

1. **股票池**：按流通市值取前 N 只（默认 500/1200），剔除 ST、退市、北交所、科创板、上市不满一年、20 日日均成交额低于 1 亿的个股。
2. **选股打分**（截面 z-score）：
   `score = 1.0 × 120日动量 − 0.5 × 20日涨幅 − 0.3 × 20日年化波动`
   - 120 日动量：中期趋势的核心来源
   - 减 20 日涨幅：规避短期过热后的反转
   - 减波动率：低波因子在 A 股长期有效，也能降低回撤
3. **硬性过滤**：收盘价 > 60 日均线，且 120 日动量为正。
4. **大盘择时**：沪深 300 收盘价 ≤ 20 日均线 → 全部清仓空仓等待。这是 A 股最有效的单条风控规则。
5. **个股风控**（每日盘后检查，次日开盘执行）：
   - 相对买入价亏损 12% → 止损
   - 收盘跌破 20 日均线 → 离场
6. **调仓节奏**：每月最后一个交易日收盘出信号，次月第一个交易日开盘执行，等权 10 只，单票上限 12%。

## 交易摩擦（回测已全部计入）

- 佣金万 2.5，单边最低 5 元；印花税千 1（卖出）；过户费万 0.1
- 滑点 0.1%（买入上浮、卖出下压）
- 一手 100 股取整
- 停牌不可交易；**开盘涨停不可买、开盘跌停不可卖**
- 信号用 T 日收盘数据，成交价用 T+1 开盘价 —— 不存在未来函数

## 使用方法

```bash
pip install pandas numpy pyarrow requests matplotlib

# 回测（首次会抓数据，约 30-60 分钟；之后走缓存）
python3 run_backtest.py --start 2016-01-01 --end 2026-09-10 --tag base

# 对照组：关闭大盘择时，看择时到底有没有用
python3 run_backtest.py --no-timing --tag notiming

# 实盘信号（每个交易日 15:05 之后运行）
python3 live_signal.py --positions positions.json
```

`positions.json` 记录你的真实持仓：

```json
{
  "cash": 100000,
  "positions": {"600519": {"shares": 100, "cost_price": 1500.0}}
}
```

输出 `orders_YYYY-MM-DD.csv`，次日 9:30 之后照单执行即可（建议分 2-3 笔下单，减少冲击成本）。

## 实操纪律（比策略本身更重要）

1. **不许手动否决信号**。回测收益来自完整执行，漏掉几笔就完全不是这条曲线了。
2. **不加杠杆**。融资盘在择时失效的月份会直接把你打穿。
3. **资金量**：10 只等权、单票 1 手起，建议 ≥ 20 万，否则最低佣金 5 元和整手取整会显著吃掉收益。
4. **接受空仓**。策略在大盘走弱时会长期空仓，这是收益的一部分，不是"没干活"。
5. **先纸面跑 3 个月**：每天生成信号并记录，对比实际成交价与信号价的偏差，再上真钱。
6. **单月亏损超过 15%** 或连续 6 个月跑输沪深 300 → 停下来检查策略是否失效，不要加仓摊平。

## 已知局限（必须知道）

- **幸存者偏差**：股票池取自当前上市清单，已退市个股不在其中，回测收益偏乐观。要彻底修正需要付费的 point-in-time 数据（tushare pro / 聚宽 / wind）。
- **股票池是当前市值排序**，不是历史时点排序，存在轻微前视偏差。
- **前复权价格**随分红除权变动，历史序列会随时间小幅变化，属行业通用做法。
- **免费接口**有频率限制且偶尔断连，代码里已做重试；跑实盘建议换 tushare pro 或券商行情。
- **参数是先验设定的**（120/20/60/12%），没有做大规模网格搜索——这是刻意的，避免过拟合。改参数前请先做样本外验证。

## 想要更高收益的正确方向

不是调参数把回测拉到月化 15%，而是：

1. **换更好的数据**：财务因子、分析师一致预期、龙虎榜、北向资金持股（需付费源）。
2. **做指数增强**：以中证 500/1000 为基准控制行业与市值暴露，追求稳定超额而非绝对收益。
3. **提高换手频率**：日内 T0、隔夜反转等，但对交易成本和执行能力要求高。
4. **多策略组合**：动量 + 反转 + 低波 + 打新，降低单策略失效风险。
